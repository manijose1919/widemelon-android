# Releases

Do **not** commit APK binaries here (they are ~50 MB and trip GitHub size warnings).

## Get a build

1. **GitHub Actions** → workflow **WideMelon Debug APK** → download the `WideMelonDS-debug` artifact  
2. Or build locally: see [docs/BUILDING.md](../docs/BUILDING.md)

## Optional: GitHub Release

Attach `app-gitHub-prod-debug.apk` (or a signed release) to a GitHub Release tag such as `v2.0.4-widescreen`.
